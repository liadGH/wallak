# Wallak

A personal gym-progression app for iPhone: workouts, progress charts, bodyweight, food and goals.

It's an installable web app. Open the site in Safari, tap **Share → Add to Home Screen**, and it runs full-screen like a normal app, including offline.

All data is stored on the phone only. Use **Settings → Back up now** regularly and save the file to iCloud Drive.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
- `sw.js`: offline support
- `manifest.webmanifest`: app name, colours and icons
- `icons/`: home-screen icons, generated by `tools/make_icons.py`

## Updating

Push changes to the `main` branch. GitHub Pages republishes within a minute or two, and the app picks up the new version the next time it's opened with an internet connection. Keep the site address the same, because the phone's saved data belongs to that address.
